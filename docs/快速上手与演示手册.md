# 五工具数据平台快速上手与演示手册

这份手册面向第一次使用平台的人。按顺序操作即可，不需要了解 Agent OS、原子工具或上游仓库代码。

## 1. 这个平台能做什么

平台把五个工具放在同一个本机网站中：

| 工具 | 最适合做什么 | 输入 | 输出 |
|---|---|---|---|
| Synthetic Data Kit | 批量生成训练数据 | 文档、JSON、JSONL | QA、CoT、摘要、格式化训练数据 |
| Easy Dataset | 可视化制作和审核问答数据 | 文档、领域主题、图片 | 问答、CoT、蒸馏数据、评估题 |
| SynLogic | 生成可以被规则程序验证的逻辑题 | 数量和迷宫参数 | Arrow Maze 题目、答案和验证结果 |
| KAQG | 从专业文档构建知识并出题 | 带文本层 PDF | 图谱、分难度单选题、证据和评分 |
| Cleanlab | 检查分类数据质量 | CSV、JSON、JSONL | 错标签、异常、重复、人工决策和清洗文件 |

推荐学习顺序：

```text
Easy Dataset → SynLogic → Cleanlab → KAQG → Synthetic Data Kit
```

Easy Dataset 最容易理解；SynLogic 展示规则验证；Cleanlab 展示本机质量检查；KAQG 展示图谱增强出题；Synthetic Data Kit 更适合批处理流水线。

## 2. 打开平台

如果服务已经运行，直接打开：

```text
http://127.0.0.1:5173
```

如果页面打不开，在终端执行：

```bash
cd integrated-system
export LLM_CREDENTIAL_ROTATED=true
export LLM_MODEL=MiniMax-M3
export LLM_JUDGE_MODEL=MiniMax-M3
./scripts/dev.sh
```

这里不会显示或写入 API Key。`MINIMAX_API_KEY` 需要提前存在于本机环境变量中。

运行健康检查：

```bash
./scripts/health.sh
```

正常结果应包括：

```text
Gateway：127.0.0.1:18000 可用
Web：127.0.0.1:5173 可用
Easy Dataset：127.0.0.1:1717 可用
```

## 3. 第一次使用先检查设置

点击左侧“设置”。

文本模型区域应该显示：

```text
生成模型：MiniMax-M3
Judge 模型：MiniMax-M3
密钥状态：已验证
```

如果显示“等待验证”，点击“测试连接”。只有最小真实请求成功后，页面才会显示“已验证”。

本地服务区域应该显示：

- Gateway：可用
- Easy Dataset sidecar：可用
- Synthetic CLI：可用
- SynLogic 仓库：可用
- Cleanlab：可用
- KAQG worker、Neo4j、Mosquitto：可用

视觉模型目前没有配置，因此图片问答和多模态 QA 会保持禁用。这是正常状态，不代表文本模型有问题。

## 4. 项目是什么

每个工具页面顶部都有项目选择器。项目可以理解为该工具自己的工作文件夹或 Session。

例如：

```text
Easy Dataset 项目：产品功能文档实验
Synthetic 项目：产品文档 CoT 实验
SynLogic 项目：Arrow Maze 演示
KAQG 项目：运维规范试题
Cleanlab 项目：工单标签检查
```

五个工具的项目互不混用。Easy Dataset 上传的文档不会自动出现在 Synthetic 或 KAQG 页面。

项目支持：

- 新建
- 切换
- 重命名
- 归档

刷新网页后，平台会恢复每个工具最后打开的项目。

## 5. Easy Dataset：生成一条真实文档问答

这是最推荐的第一个案例。

### 5.1 查看已经生成的示例

1. 点击左侧“Easy Dataset”。
2. 当前项目选择“产品功能文档实验”。
3. 保持“文档问答”标签。
4. 向下滚动到“本次结果”。

当前真实结果应显示：

```text
状态：已完成
样本：1 / 1
模型：MiniMax-M3
```

真实问题是：

```text
高质量数据集产品提供了哪些核心的数据处理能力？
```

页面中可以直接查看和修改：

- 问题
- 答案
- 思维链
- 来源文件
- 评分
- 人工审核状态

### 5.2 自己重新生成

1. 勾选上传区中的文档。
2. 如需先检查原文，点击“导入并预览文本块”。
3. 数据形态选择“单轮问答”。
4. 第一次测试把目标数量改为 `1`。
5. 点击“开始生成”。
6. 等待四个阶段完成。

页面阶段会依次显示：

```text
检查服务 → 导入并分块 → 生成数据 → 整理结果
```

本机实测单条数据约需 30 秒。生成数量越多，模型调用时间和费用越高。

### 5.3 单轮、多轮和 GA 扩增怎么选

| 选项 | 什么时候使用 |
|---|---|
| 单轮问答 | RAG、知识库问答、普通指令微调 |
| 多轮对话 | 客服对话、智能助手对话训练 |
| 两者都生成 | 同时需要问答集和对话集 |
| GA 文体—受众扩增 | 原始材料较少，希望问题表达更丰富 |

第一次使用建议关闭 GA，只生成 1～5 条单轮问答。确认质量后再扩大数量。

## 6. Easy Dataset：其他三种功能

### 6.1 数据蒸馏

数据蒸馏不要求上传文档，而是从领域主题向下生成标签和问题。

示例参数：

```text
领域主题：高质量安全数据集
标签层级：2
每层标签数：2
每个标签问题数：2
```

预计叶子问题量为：

```text
2² × 2 = 8 条
```

不要一开始设置过大的层级和标签数，因为数量会指数增长。

### 6.2 评估数据

评估数据适合给模型或 RAG 系统制作测试集。

操作方法：

1. 上传并勾选文档。
2. 切换到“评估数据”。
3. 选择判断题、单选题、多选题、简答题或开放题。
4. 每种题型先设置 `1`。
5. 生成后检查正确答案和来源。

### 6.3 图片问答

图片问答支持图片、PDF 和 ZIP，但必须配置独立视觉模型。

当前页面显示“视觉模型未配置”时：

- 可以查看参数和上传格式。
- “开始生成”会保持禁用。
- 平台不会把 MiniMax M3 文本模型误当成视觉模型。
- 平台不会伪造图片问答结果。

## 7. SynLogic：生成并验证 Arrow Maze

SynLogic 不需要 API Key，适合稳定演示。

### 7.1 普通演示

1. 点击左侧“SynLogic”。
2. 选择项目“Arrow Maze 演示”。
3. 点击“20 条演示”。
4. 点击“生成并验证”。

推荐参数：

```text
数量：20
宽度：5
高度：5
预填比例：0.3～0.9
最大尝试次数：10000
```

完成后可以查看：

- 题目网格
- 标准答案网格
- 上一题和下一题
- 随机抽样
- 原始验证器结果

### 7.2 演示错误答案被拒绝

1. 先使用标准答案点击“调用原始验证器”，结果应通过。
2. 点击“人为破坏一格”。
3. 再次调用验证器，结果必须失败。

这个案例说明 SynLogic 生成的不只是文本题目，还带有可以自动判断答案是否正确的规则验证器。

### 7.3 压力测试

点击“1,000 条验收”可以运行压力测试。

当前本机已经验证：

```text
生成：1000
验证通过：1000
通过率：100%
破坏答案：成功拒绝
```

## 8. Synthetic Data Kit：生成 QA 或 CoT

Synthetic Data Kit 更适合批量流水线。

当前已经验证它能真实解析文档并生成 Lance 产物；使用现有文本模型执行完整 QA、CoT 和筛选链路仍属于下一项验收。因此第一次运行请从 3 条开始，并检查最终样本和日志，不能只看任务是否启动。

页面提供：

- 普通 QA
- CoT 思维链
- 文档摘要
- 为已有对话补充 CoT
- 多模态 QA

### 8.1 第一次建议这样运行

1. 点击左侧“Synthetic Data Kit”。
2. 选择项目“产品文档 CoT 实验”。
3. 上传并勾选文档。
4. 选择“普通 QA”或“CoT 思维链”。
5. 数量先设置为 `3`。
6. 展开高级设置并保持默认值。
7. 点击开始生成。

默认高级参数：

```text
分块大小：4000
分块重叠：200
筛选阈值：7.0
模型：MiniMax-M3
```

平台会自动执行：

```text
检查环境 → 解析输入 → 生成数据 → 质量筛选 → 整理结果
```

多模态 QA 需要视觉模型；当前未配置时按钮保持禁用。

## 9. KAQG：从 PDF 生成图谱试题

1. 打开 KAQG，新建项目“运维规范试题”。
2. 上传 `demo-inputs/kaqg/数据平台运维与质量规范.pdf`。
3. 领域填写“数据平台运维规范”，三个难度各填 `3`。
4. 点击“构建图谱并生成试题”。
5. 完成后查看图谱摘要、9 道题的证据与评估分数，并下载三类产物。

这是模型任务。设置页文本模型未验证，或 KAQG、Neo4j、MQTT 任一服务不可达时，不应反复提交任务，应先修复对应连接状态。

## 10. Cleanlab：检查工单标签

1. 打开 Cleanlab，新建项目“工单标签检查”。
2. 上传 `demo-inputs/cleanlab/数据质量工单.csv`。
3. 列名保持 `id / text / label`，直接启动本机检查。
4. 按标签质量分数和异常分数查看最可疑样本。
5. 分别测试接受建议、保留原标签和手动标签，再导出 CSV、JSONL 和审计报告。

这一步不需要 API Key。测试包中的答案文件给出了植入问题和验收门槛，便于判断算法是否真的找到问题。

## 11. 如何审核样本

生成完成后，不需要跳转到另一个“审核中心”。当前工具页面会直接显示样本。

每条样本可以：

1. 修改问题。
2. 修改答案。
3. 修改思维链。
4. 点击“保存修改”。
5. 点击“确认样本”或“驳回样本”。

建议重点检查：

- 答案是否忠于原文。
- 是否出现原文没有的事实。
- 问题是否完整、自然。
- 答案是否真正回答问题。
- 思维链是否与最终答案一致。
- 多条样本之间是否重复。

## 12. 如何导出

每个工具页面底部都有导出按钮。

| 格式 | 用途 |
|---|---|
| JSONL | 保留完整样本和数据血缘，最推荐 |
| Alpaca | 指令微调 |
| OpenAI FT | OpenAI 兼容微调格式 |
| ChatML | 多轮消息格式 |
| Hugging Face | 数据集加载与后续处理 |
| CSV | 人工查看、Excel 审核 |

平台会在下载前重新解析文件。解析成功时，后端响应包含：

```text
X-Sample-Count: 样本数量
X-Parse-Validated: true
```

## 13. 已完成任务怎么用

左侧“已完成任务”默认只显示成功且有产物的任务。

可以按以下条件筛选：

- 工具
- 项目
- 功能类型
- 时间

如果要看失败记录，打开“需要处理”。失败任务会显示普通阶段行和错误说明，不使用竖向 Timeline。

## 14. 常见问题

### 页面显示“未配置文本模型密钥”

说明启动 Gateway 的进程没有继承 `MINIMAX_API_KEY`。在同一个终端环境中重新启动服务。

### 页面显示“等待最小请求验证”

进入“设置”，点击文本模型下的“测试连接”。

### Easy Dataset 服务未启动

检查：

```text
http://127.0.0.1:1717/api/projects
```

然后运行：

```bash
./scripts/dev.sh
```

### 为什么“开始生成”按钮是灰色

通常是以下原因之一：

- 没有选择项目。
- 没有勾选输入文件。
- 文本模型尚未验证。
- Easy Dataset sidecar 未启动。
- 当前功能需要视觉模型，但视觉模型未配置。

按钮下方会显示具体原因。

### 生成完成但结果质量一般

先不要直接扩大数量。可以：

- 换一份结构更清晰的材料。
- 减小分块大小。
- 提高质量筛选阈值。
- 关闭 GA 扩增做基准测试。
- 人工修改并确认合格样本。

## 15. 五分钟演示顺序

如果需要向老师或同学演示，建议按以下顺序：

1. 打开“设置”，展示文本模型状态和五个工具的本地组件状态。
2. 打开 Easy Dataset，展示真实问题、答案、CoT 和来源文档。
3. 点击 JSONL 导出，说明导出前会做解析校验。
4. 打开 SynLogic，展示题目网格和标准答案。
5. 人为破坏一个答案，再调用原始验证器，展示错误答案被拒绝。
6. 打开 Cleanlab，展示一条错标签建议和原标签保留。
7. 打开 KAQG，展示图谱事实、分难度题目和来源证据。
8. 最后打开 Synthetic Data Kit，说明它适合批量 QA、CoT 和训练格式转换。

这套演示覆盖文档生成、规则验证、知识图谱出题和分类数据质量检查。
