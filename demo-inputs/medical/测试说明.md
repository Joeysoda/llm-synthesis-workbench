# 医疗领域包测试说明

医疗领域包不接收真实病例，因此没有可上传的病历样本。本页面的测试输入是“患者参数”，由 Synthea 在本机按固定随机种子生成完全虚构的记录。

推荐首次参数：

```text
人口数量：50
随机种子：20260814
年龄：18–80
性别：全部
```

完成后在 `runtime/medical/<医疗项目 ID>/<流程运行 ID>/` 查看：

- `synthea/`：Synthea 原始 FHIR、Bulk FHIR 和 CSV 输出；
- `patient-timelines.jsonl`：按虚构患者 ID 排序的时间线；
- `medical-task-samples.jsonl`：至少 20 条带来源资源 ID 的任务样本；
- `quality-report.json`：FHIR 解析、引用关系、任务数量与 Synthea 合成联系方式格式记录；
- `data-card.md` 与 `dataset-manifest.json`：用途、限制、许可证、质量和血缘。

`预期质量门禁.json` 只用于核对结果结构，不包含或模拟任何真实患者信息。
